# 🚀 Quick Start Guide

## Starte in 3 Schritten:

### 1️⃣ Dependencies installieren
```bash
pip3 install -r requirements.txt
```

### 2️⃣ Server starten
```bash
python3 backend.py
```

### 3️⃣ Im Browser öffnen
```
http://localhost:5000
```

## 🎉 Fertig!

Die Anwendung läuft jetzt und du kannst:

- 🎲 **Sichere Passwörter generieren** (Tab: Generator)
- 📊 **Passwort-Stärke prüfen** (Tab: Checker)
- 🔤 **Merkbare Passphrasen erstellen** (Tab: Passphrase)
- ⚠️ **Auf Datenlecks prüfen** (Tab: Breach Check)

## 💡 Tipps

- **Passwort kopieren**: Klicke auf das 📋 Symbol
- **Neu generieren**: Nutze den 🔄 Button
- **Einstellungen**: Passe Länge und Zeichentypen an
- **Enter-Taste**: Funktioniert in allen Eingabefeldern

## 🔒 Sicherheit

- Alle Passwörter werden **lokal** generiert
- **Keine Speicherung** auf einem Server
- Breach-Check nutzt **k-Anonymität** (100% sicher)
